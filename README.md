## 📌 Project Overview

**Smart Resume AI** is a one-stop resume assistant that helps you:

- 📤 Upload your resume (PDF/DOCX)
- 🤖 Get instant AI feedback using OpenAI or Google Gemini
- 🧾 Build a clean, modern resume
- 💼 Search jobs across top portals (LinkedIn, Naukri, etc.)

Whether you're a **fresher** or a **working professional**, this app offers tailored suggestions to improve your chances of landing interviews!

---

## ✨ Features

✅ Upload resumes in **PDF/DOCX**  
✅ Choose between **Standard** or **AI-powered** feedback  
✅ Get suggestions based on **job roles**  
✅ Build resume with **modern templates**  
✅ Search jobs from **multiple platforms**  
✅ Easy-to-use, beautiful **UI with Streamlit**
