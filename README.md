
# 🧠 AI Resume Analyzer

**AI Resume Analyzer** is a Streamlit-based web application that lets users upload resumes (PDF or DOCX format) and receive AI-powered feedback and suggestions using OpenAI or Gemini models. It helps evaluate resume quality, identify missing sections, and provide role-specific improvements.

## 📌 Features

- 📄 Upload resumes in **PDF or DOCX**
- 🧠 Get resume analysis via **OpenAI** or **Gemini AI**
- 📌 Role-based suggestions and skill matching
- 📑 Resume builder with modern templates
- 🌐 Job search integrated with platforms like LinkedIn, Naukri, and more

---

## 🛠 Tech Stack

| Tech         | Usage                            |
|--------------|----------------------------------|
| Streamlit    | Web application UI               |
| OpenAI API   | Natural Language Resume Analysis |
| Gemini       | Alternate AI model               |
| Python       | Backend & processing             |
| Pillow, docx | File and image handling          |
